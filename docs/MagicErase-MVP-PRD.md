## 1. 产品概述

### 1.1 产品定位
MagicErase 是一款基于 AI 的在线图片擦除工具，用户可一键移除图片中的不需要的物体、人物或瑕疵，AI 自动智能填充背景。

### 1.2 产品愿景
让图片编辑像魔法一样简单——无需专业技能，3 步完成专业级修图。

### 1.3 MVP 目标
- ✅ 验证核心功能（AI 擦除）的用户需求
- ✅ 测试技术可行性（Cloudflare + Clipdrop）
- ✅ 收集用户反馈，迭代优化
- ✅ 控制成本，快速上线（1 周内完成）

### 1.4 成功指标
| 指标 | 目标值 |
|------|--------|
| 日活跃用户 | 50+ |
| 图片处理量 | 100+ 张/天 |
| 用户留存率（7 日） | 30%+ |
| 平均处理时长 | < 5 秒 |
| 用户满意度 | 4.0/5.0+ |

## 2. 目标用户

### 2.1 主要用户群体
| 用户类型 | 特征 | 使用场景 |
|----------|------|----------|
| 普通用户 | 无修图技能，想快速处理照片 | 移除照片中的路人、杂物 |
| 电商卖家 | 需要处理商品图片 | 移除背景、水印、瑕疵 |
| 社交媒体用户 | 频繁发图，追求美观 | 清理照片中的干扰元素 |
| 内容创作者 | 自媒体、博主 | 快速产出高质量配图 |

### 2.2 用户痛点
- ❌ 传统修图软件学习成本高（PS 太复杂）
- ❌ 在线工具效果差，边缘不自然
- ❌ 担心隐私泄露（图片被存储）
- ❌ 付费工具价格高

### 2.3 MagicErase 解决方案
- ✅ 3 步操作：上传 → 涂抹 → 下载
- ✅ AI 智能填充，效果自然
- ✅ 图片不存储，全程内存处理
- ✅ 免费额度 + 按需付费

## 4. 技术架构

### 4.1 整体架构
```
┌─────────────┐     ┌──────────────────┐     ┌──────────────┐
│   用户浏览器  │ ──→ │ Cloudflare Workers│ ──→ │ Clipdrop API │
│  (前端页面)  │ ←── │  (路由 + 内存处理) │ ←── │  (AI 处理)    │
└─────────────┘     └──────────────────┘     └──────────────┘
                           │
                           ↓
                    ┌─────────────┐
                    │ Cloudflare  │
                    │   Pages     │
                    │ (静态资源)   │
                    └─────────────┘
```

### 4.2 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| **前端** | HTML5 + CSS3 + Vanilla JS | 零框架依赖，极致轻量 |
| **画布** | Canvas API | 图片展示与涂抹交互 |
| **后端** | Cloudflare Workers | 无服务器，边缘计算 |
| **AI 服务** | Clipdrop Cleanup API | 物体移除与背景填充 |
| **部署** | Cloudflare Pages + Workers | 一体化部署 |
| **域名** | 自定义域名（可选） | 品牌化 |

### 4.3 数据流

```
1. 用户上传图片 → 前端 Canvas 展示
2. 用户涂抹标记 → Canvas 生成 mask 图片
3. 点击处理 → 前端发送 {image, mask} 到 Workers
4. Workers 转发 → Clipdrop API
5. Clipdrop 返回 → Workers 透传给前端
6. 前端展示结果 → 用户下载
```

### 4.4 安全设计
- ✅ 图片不存储，全程内存处理
- ✅ HTTPS 加密传输
- ✅ API Key 存储在 Workers 环境变量（不暴露给前端）
- ✅ 请求频率限制（防止滥用）
- ✅ 文件大小限制（最大 10MB）

## 5. 用户流程

### 5.1 核心流程
```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  访问网站 │ →  │ 上传图片 │ →  │ 涂抹标记 │ →  │ AI 处理  │ →  │ 下载结果 │
└─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
   1 秒           2 秒           5 秒           3-5 秒          1 秒
   
总耗时：约 12 秒
```

### 5.2 详细步骤

#### Step 1: 访问网站
- 用户打开 `https://magicerase.app`
- 加载首页（< 1 秒）
- 显示产品说明和示例

#### Step 2: 上传图片
- 点击「上传图片」按钮 或 拖拽上传
- 支持格式：JPG, PNG, WebP
- 大小限制：≤ 10MB
- 图片加载到 Canvas 画布

#### Step 3: 涂抹标记
- 默认画笔工具自动激活
- 在图片上涂抹要擦除的区域
- 红色半透明覆盖层显示涂抹区域
- 可调整画笔大小（P1 功能）
- 可清除重画

#### Step 4: AI 处理
- 点击「开始擦除」按钮
- 显示加载动画（3-5 秒）
- 前端发送图片 + mask 到后端
- Workers 调用 Clipdrop API
- 接收处理结果

#### Step 5: 下载结果
- 展示处理后的图片
- 对比切换（原图/处理后）
- 点击「下载」保存 PNG
- 可选择重新编辑或处理新图片

## 7. API 设计

### 7.1 内部 API（Cloudflare Workers）

#### POST /api/erase
**描述：** 处理图片擦除请求

**请求：**
```
Content-Type: multipart/form-data

参数:
- image: File (图片文件，JPG/PNG/WebP)
- mask: File (掩码图片，PNG 黑白图)
```

**响应：**
```
Content-Type: image/png
Body: 处理后的图片二进制数据
```

**错误码：**
| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 413 | 文件过大（>10MB） |
| 429 | 请求频率超限 |
| 500 | 服务器错误 |

### 7.2 外部 API（Clipdrop）

#### POST https://clipdrop-api.co/cleanup/v1
**描述：** Clipdrop 物体移除 API

**请求：**
```
Headers:
  x-api-key: <API_KEY>
  Content-Type: multipart/form-data

参数:
- image_file: File (原始图片)
- mask_file: File (涂抹掩码)
```

**响应：**
```
Content-Type: image/png
Body: 处理后的图片
```

**文档：** https://clipdrop.co/apis

## 8. 性能指标

### 8.1 性能目标
| 指标 | 目标值 | 测量方式 |
|------|--------|----------|
| 首屏加载时间 | < 1 秒 | Lighthouse |
| 图片上传时间 | < 2 秒 (5MB 图片) | 前端埋点 |
| API 响应时间 | < 5 秒 | Workers 日志 |
| 端到端处理时长 | < 10 秒 | 用户感知 |
| 可用性 | 99.9% | Cloudflare 监控 |

### 8.2 优化策略
- ✅ 使用 Cloudflare 全球 CDN 加速静态资源
- ✅ 图片压缩后再上传（前端 Canvas 压缩）
- ✅ 懒加载非关键资源
- ✅ 启用 HTTP/2 和 Brotli 压缩
- ✅ Workers 边缘节点就近处理

### 8.3 监控方案
- Cloudflare Workers 内置日志
- 前端错误上报（可选：Sentry）
- 性能监控（可选：Cloudflare Web Analytics）

## 10. 风险与假设

### 10.1 技术风险
| 风险 | 影响 | 应对措施 |
|------|------|----------|
| Clipdrop API 不稳定 | 高 | 准备备用 API（Replicate/Stability AI） |
| Cloudflare Workers 超时 | 中 | 优化代码，确保 <10 秒完成 |
| 大图片处理失败 | 中 | 限制最大尺寸（4096px），前端压缩 |
| 移动端兼容性问题 | 低 | 充分测试主流浏览器 |

### 10.2 业务风险
| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 用户量激增导致成本超支 | 中 | 设置每日配额，超限提示 |
| 竞品价格战 | 低 | 强调隐私保护（不存储图片） |
| 用户需求不符预期 | 高 | 快速上线验证，收集反馈迭代 |

### 10.3 关键假设
- ✅ Clipdrop API 效果满足用户需求
- ✅ 用户接受免费 + 按量付费模式
- ✅ Cloudflare 免费额度足够 MVP 阶段使用
- ✅ 目标用户能找到产品（需要基础推广）
