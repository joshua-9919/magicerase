## 1. 产品概述

### 1.1 产品定位
MagicErase 是一款基于 AI 的在线图片擦除工具，用户可一键移除图片中的不需要的物体、人物或瑕疵，AI 自动智能填充背景。

### 1.2 产品愿景
让图片编辑像魔法一样简单——无需专业技能，3 步完成专业级修图。

### 1.3 MVP 目标
- ✅ 验证核心功能（AI 擦除）的用户需求
- ✅ 测试技术可行性（Next.js + Clipdrop）
- ✅ 收集用户反馈，迭代优化
- ✅ 控制成本，快速上线（1 周内完成）

### 1.4 成功指标
| 指标 | 目标值 | 当前状态 |
|------|--------|----------|
| 日活跃用户 | 50+ | 待上线 |
| 图片处理量 | 100+ 张/天 | 待上线 |
| 用户留存率（7 日） | 30%+ | 待上线 |
| 平均处理时长 | < 5 秒 | 待测试 |
| 用户满意度 | 4.0/5.0+ | 待测试 |

## 2. 目标用户

### 2.1 主要用户群体
| 用户类型 | 特征 | 使用场景 |
|----------|------|----------|
| 普通用户 | 无修图技能，想快速处理照片 | 移除照片中的路人、杂物 |
| 电商卖家 | 需要处理商品图片 | 移除背景、水印、瑕疵 |
| 社交媒体用户 | 频繁发图，追求美观 | 清理照片中的干扰元素 |
| 内容创作者 | 自媒体、博主 | 快速产出高质量配图 |

### 2.2 用户痛点
- ❌ 传统修图软件学习成本高（PS 太复杂）
- ❌ 在线工具效果差，边缘不自然
- ❌ 担心隐私泄露（图片被存储）
- ❌ 付费工具价格高

### 2.3 MagicErase 解决方案
- ✅ 3 步操作：上传 → 涂抹 → 下载
- ✅ AI 智能填充，效果自然
- ✅ 图片不存储，全程内存处理
- ✅ 免费额度 + 按需付费
- ✅ 现代化 UI，易于使用

## 4. 技术架构

### 4.1 整体架构

```
┌─────────────┐     ┌──────────────────┐     ┌──────────────┐
│   用户浏览器  │ ──→ │   Next.js App   │ ──→ │ Clipdrop API │
│  (React 页面) │ ←── │  (API Routes)   │ ←── │  (AI 处理)    │
└─────────────┘     └──────────────────┘     └──────────────┘
                           │
                           ↓
                    ┌─────────────┐
                    │    Vercel   │
                    │   或 CF     │
                    │  (部署平台)  │
                    └─────────────┘
```

### 4.2 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| **前端框架** | Next.js 14 (App Router) | React 全栈框架 |
| **UI 库** | React 18 | 组件化开发 |
| **样式** | Tailwind CSS 3 | 原子化 CSS |
| **语言** | TypeScript 5 | 类型安全 |
| **画布** | HTML5 Canvas API | 图片编辑 |
| **API** | Next.js API Routes | 服务端路由 |
| **AI 服务** | Clipdrop Cleanup API | 物体移除 |
| **部署** | Vercel / Cloudflare Pages | 一键部署 |

### 4.3 项目结构

```
magicerase/
├── src/
│   ├── app/
│   │   ├── api/
│   │   │   └── erase/
│   │   │       └── route.ts      # API 端点
│   │   ├── globals.css           # 全局样式
│   │   ├── layout.tsx            # 根布局
│   │   └── page.tsx              # 主页面
├── public/                       # 静态资源
├── .env.local                    # 环境变量
├── next.config.js                # Next.js 配置
├── tailwind.config.js            # Tailwind 配置
├── tsconfig.json                 # TypeScript 配置
└── package.json                  # 依赖管理
```

### 4.4 数据流

```
1. 用户上传图片 → React 组件处理
2. 用户涂抹标记 → Canvas 生成 mask
3. 点击处理 → 发送到 /api/erase
4. API Route 转发 → Clipdrop API
5. Clipdrop 返回 → API Route 透传
6. React 展示结果 → 用户下载
```

### 4.5 安全设计
- ✅ 图片不存储，全程内存处理
- ✅ HTTPS 加密传输
- ✅ API Key 存储在环境变量（服务端）
- ✅ 请求频率限制（中间件实现）
- ✅ 文件大小限制（10MB）
- ✅ CORS 跨域支持

## 5. 用户流程

### 5.1 核心流程

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  访问网站 │ →  │ 上传图片 │ →  │ 涂抹标记 │ →  │ AI 处理  │ →  │ 下载结果 │
└─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
   1 秒           2 秒           5 秒           3-5 秒          1 秒
   
总耗时：约 12 秒
```

### 5.2 详细步骤

#### Step 1: 访问网站
- 用户打开 `https://magicerase.app`
- Next.js 渲染首页（< 1 秒）
- 显示渐变背景和产品展示

#### Step 2: 上传图片
- 点击「选择图片」按钮 或 拖拽上传
- 支持格式：JPG, PNG, WebP
- 大小限制：≤ 10MB
- React 处理文件并显示在 Canvas

#### Step 3: 涂抹标记
- 自动激活画笔工具
- 在图片上涂抹要擦除的区域
- 红色半透明覆盖层（rgba(239, 68, 68, 0.5)）
- 可调节画笔大小（5-100px）
- 可清除重画

#### Step 4: AI 处理
- 点击「开始擦除」按钮
- 显示加载动画和提示
- React 发送图片 + mask 到 /api/erase
- Next.js API Route 调用 Clipdrop
- 接收处理结果（3-5 秒）

#### Step 5: 下载结果
- Canvas 展示处理后的图片
- 点击「下载结果」保存 PNG
- 可选择「处理新图片」重新开始

## 7. API 设计

### 7.1 内部 API（Next.js API Routes）

#### POST /api/erase

**描述：** 处理图片擦除请求

**请求：**
```
Content-Type: multipart/form-data

参数:
- image: File (图片文件，JPG/PNG/WebP, max 10MB)
- mask: File (掩码图片，PNG 黑白图)
```

**响应（成功）：**
```
Content-Type: image/png
Status: 200
Body: 处理后的图片二进制数据
```

**响应（错误）：**
```json
{
  "error": "错误描述"
}
```

**错误码：**
| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 413 | 文件过大（>10MB） |
| 500 | 服务器错误 |

**代码位置：** `src/app/api/erase/route.ts`

### 7.2 外部 API（Clipdrop）

#### POST https://clipdrop-api.co/cleanup/v1

**描述：** Clipdrop 物体移除 API

**请求：**
```
Headers:
  x-api-key: <CLIPDROP_API_KEY>
  Content-Type: multipart/form-data

参数:
- image_file: File (原始图片)
- mask_file: File (涂抹掩码)
```

**响应：**
```
Content-Type: image/png
Body: 处理后的图片
```

**文档：** https://clipdrop.co/apis

## 10. 部署方案

### 10.1 部署到 Vercel（推荐）

**步骤：**

1. **推送代码到 GitHub**
   ```bash
   git push origin main
   ```

2. **导入到 Vercel**
   - 访问 https://vercel.com
   - Import Git Repository
   - 选择 `magicerase` 项目

3. **配置环境变量**
   ```
   CLIPDROP_API_KEY=your_api_key_here
   ```

4. **部署**
   - 点击 Deploy
   - 自动构建和部署

**成本：** 免费（Hobby 计划）

### 10.2 部署到 Cloudflare Pages

**步骤：**

1. **安装 Wrangler**
   ```bash
   npm install -g wrangler
   ```

2. **登录 Cloudflare**
   ```bash
   wrangler login
   ```

3. **构建项目**
   ```bash
   npm run build
   ```

4. **部署**
   ```bash
   wrangler pages deploy .next
   ```

**成本：** 免费（10 万请求/天）
